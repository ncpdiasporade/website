# History archive image credits

The locally stored images in this folder are resized WebP derivatives used by the interactive history archive.

- `fall.webp` — [Protestors celebrating the fall of Sheikh Hasina](https://commons.wikimedia.org/wiki/File:Protestors_celebrating_the_fall_of_Sheikh_Hasina.jpg), Saakibrahman, CC0.
- `parliament.webp` — [Parliament storming on August 5, 2024](https://commons.wikimedia.org/wiki/File:Parliament_storming_on_August_5,_2024.jpg), Shazid Ahsan, CC BY-SA 4.0.
- `rana-plaza.webp` — [2013 Savar building collapse aftermath](https://commons.wikimedia.org/wiki/File:2013_Savar_building_collapse_aftermath.jpg), Sudipta06, CC BY-SA 3.0.
- `road-safety.webp` — [Bangladesh road-safety protests](https://commons.wikimedia.org/wiki/File:Bangladesh_road-safety_protests.jpg), Jubair1985, CC BY-SA 4.0.

Remote Human Rights Watch images are loaded from the source pages listed in `app.js`; every incident dossier links back to the corresponding original report. Context images are explicitly labelled when they do not depict the precise instant described by the record.
